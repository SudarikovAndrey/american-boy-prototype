# «Америкэн бой» — играбельный прототип LiveOps-ивента

Прототип экономического ивента для «Рынок Пацана» / Block Boss. Один HTML-файл, играть с телефона:
**https://sudarikovandrey.github.io/american-boy-prototype/**

Условная графика, баланс в объекте `CFG` внутри `index.html`. Прогресс хранится в браузере.
